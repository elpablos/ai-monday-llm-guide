# Ilustrace aktuální prezentace

Černobílý doodle styl: silné obrysy, bílé plochy, jednoduché postavy. Pět hlavních PNG používá společné umístění `.story-art` v `style.css`.

| Soubor | Obsah | Slide |
|---|---|---|
| `robot-explorer-simple.png` | robot otevírá krabičku LLM | 1 |
| `pavel-portrait-simple.png` | kreslený portrét Pavla | 2 |
| `pavel-archaeologist.png` | Pavel s lupou odkrývá krabičku | 3 |
| `world-compression.svg` | svěrák se zeměkoulí, metafora komprese | 14 |
| `calculator.svg` | kalkulačka s přesným výsledkem | 24 |
| `robot-question-simple.png` | Terminátor / Transformer s otazníkem | 30 |
| `robot-finale-simple.png` | mávající robot u zavřené krabičky | 30, závěr |

PNG vytvořil imagegen pro tuto prezentaci. Lidské postavy vycházejí z [GitHub avataru dodaného Pavlem](https://avatars.githubusercontent.com/u/11454911). Stylovou předlohou sjednocené sady je `pavel-archaeologist.png`. Podrobnější původ viz `../../sources.md`.

SVG jsou vlastní editovatelné kresby. Další historické piktogramy jsou přímo v `../doodles.js`, diagramy v `../slides.js`. Nemají build krok ani externí závislosti.

Starší Skullpix pokusy a nahrazené varianty ilustrací jsou dostupné pouze v historii Gitu, např. v commitu `ee49094`.
